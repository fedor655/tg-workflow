# tg-workflow

Личный тулкит, который превращает **созвоны и переписки в текст**, а текст —
в разборы, задачи и выжимки вместе с ассистентом (Claude Code).

Два скрипта:

- **`_выгрузка_тг.py`** — подтягиватель. Читает твои собственные Telegram-чаты
  через официальный API и выгружает их в текст с таймкодами. Голосовые
  расшифровываются на лету.
- **`_stt.py`** — расшифратор. Превращает запись созвона (mkv/mp4/mp3/…) в текст
  с таймкодами.

Оба гонят звук через Whisper large-v3 (на GPU, если есть; иначе на CPU).

## Связка: как это работает

```
   ┌─────────────┐     ┌──────────────┐     ┌─────────────┐     ┌──────────────┐
   │  созвон      │     │ расшифровка   │     │  ассистент  │     │  результат   │
   │  (запись)    │ ──► │ Whisper       │ ──► │  читает     │ ──► │  разбор,     │
   │  Telegram    │     │ large-v3      │     │  текст      │     │  задачи,     │
   │  (выгрузка)  │     │               │     │             │     │  выжимка     │
   └─────────────┘     └──────────────┘     └─────────────┘     └──────────────┘
          ▲                                                              │
          └──────────────────────  повтор после каждого созвона  ────────┘
```

1. **Собираем сырьё.** Созвон пишется в файл; переписка выгружается
   `_выгрузка_тг.py`. Один источник — голос и текст.
2. **Расшифровываем.** `_stt.py` для файлов записи, сам подтягиватель — для
   голосовых из чатов. На выходе — текст с таймкодами, по которому можно искать
   любую фразу.
3. **Ассистент читает текст** и делает то, что руками долго: разбор разговора,
   кто что решил, список задач с владельцами и сроками, гипотезы, выжимку созвона
   для команды.
4. **Петля.** После каждого нового созвона — заново выгрузить, заново
   расшифровать, обновить план по свежим данным. Ничего не пересылается вручную.

## Как всё началось

Началось с простого: «разбери папку с видео, хочу подчистить лишнее». Оттуда
выросло в расшифровку деловых созвонов, разбор целого проекта по переписке и
голосовым, а затем в постоянную поддержку следующего проекта — где каждый созвон
превращается в выжимку и обновлённый список задач.

Смысл связки — чтобы решения не жили только в голове и в голосовых, а
превращались в текст, который можно перечитать, найти и по которому видно, что
делать дальше.

## Установка

```bash
pip install -r requirements.txt
```

Плюс системно нужен **ffmpeg** в PATH. Для расшифровки на видеокарте — CUDA
(без неё всё работает на CPU, просто медленнее).

## Настройка

1. Получить `api_id` / `api_hash` на <https://my.telegram.org> → API development tools.
2. Скопировать `_tg_secret.example.py` → `_tg_secret.py` и вписать туда ключи.
3. В `_выгрузка_тг.py` задать список `CHATS` (id, @username или примерное имя)
   и дату `SINCE`.

## Запуск

- **Выгрузить чаты:** запустить `_выгрузить из тг.bat` (или `python _выгрузка_тг.py`).
  Первый раз Telegram спросит номер и код — вводишь сам, дальше вход запоминается.
  Результат — в папке `выгрузки/`, полный список твоих чатов — в
  `выгрузки/_список чатов.txt`.
- **Расшифровать запись:** перетащить файл на `_расшифровать.bat` (или запустить
  без аргументов — возьмёт самую свежую запись). Результат — в `расшифровки/`.

## Приватность

- Читается **только твой собственный** Telegram-аккаунт через официальный API.
- Секреты (`_tg_secret.py`), файл сессии (`_tg_session*`) и все данные
  (`выгрузки/`, `расшифровки/`, `созвоны/`, голосовые) — в `.gitignore`
  и в репозиторий не попадают.
